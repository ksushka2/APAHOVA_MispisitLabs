# Контекст лабораторной работы №4

Апахова Ксения, ИСТбд-41. Тема всех четырёх работ — информационная система детской «IT-Школы».

Работа №1 выбрала Python 3.11 и Django, работа №2 реализовала подачу и просмотр заявок родителями и сценарии отказа, работа №3 перенесла справочник курсов и заявки в PostgreSQL 18. Работа №4 оформляет эти же функции в пяти серверных страницах Django с локальным Bootstrap 5.3.8, светло-голубым фоном и бургунди-акцентами.

Заготовка «Педагог ДО» не используется как тема или источник рабочих заявок. Её модели, миграция и уже существующие данные сохранены. Маршруты работают с прежними `Course` и `StudentRequest`. Новая миграция добавляет учебные курсы только при полностью пустом справочнике; данные работ №3 не переписываются.

Сохранены `name: mispisit-apahova`, сервисы `app` и `db`, PostgreSQL 18, путь тома и имя `dbdata`. Основной Compose рассчитан на самостоятельную публикацию автором `ksushkaap/mispisit-lab1:0.0.4`. Для проверки до публикации добавлен отдельный локальный override; он не меняет требования файла сдачи.

Подробное решение, таблица библиотек и команды приведены в [README.md](README.md). В GitHub и Docker Hub в ходе подготовки ничего не публиковалось.
