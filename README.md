# IT-Школа — лабораторная работа №4

Информационная система детской IT-школы. Версия 0.0.4.

В работе оформлены страницы функций из предыдущих лабораторных: подача заявки на курс, просмотр заявок и обработка отказов. Добавлены общая навигация, оформление форм и таблиц, пустое состояние списка.

Используются Django Templates, локальный Bootstrap 5.3.8 и собственные CSS-стили. Фон светло-голубой, кнопки и ссылки — бургунди. Данные хранятся в PostgreSQL 18.

## Запуск

Репозиторий: https://github.com/ksushka2/APAHOVA_MispisitLabs

Ветка: lab4

Pull Request: https://github.com/ksushka2/APAHOVA_MispisitLabs/pull/4

Образ: ksushkaap/mispisit-lab1:0.0.4

Для запуска необходимы Git и Docker с поддержкой Docker Compose. На Windows запустите Docker Desktop и дождитесь его готовности. Порт 8080 должен быть свободен.

Откройте CMD или терминал и выполните команды по очереди:

```cmd
git clone -b lab4 https://github.com/ksushka2/APAHOVA_MispisitLabs APAHOVA_MispisitLabs-lab4
cd APAHOVA_MispisitLabs-lab4
docker compose pull
docker compose up -d
```

Команда `docker compose pull` скачивает образы приложения и PostgreSQL. Команда `docker compose up -d` запускает оба сервиса. Сборка приложения на компьютере пользователя не требуется.

Откройте в браузере: http://localhost:8080

На страницах должна отображаться версия 0.0.4.

## Повторный запуск

Из папки четвёртой лабораторной работы выполните:

```cmd
docker compose up -d
```

## Остановка

Из той же папки выполните:

```cmd
docker compose stop
```

Используется том dbdata из лабораторной работы №3. Существующие курсы и заявки сохраняются.

## Страницы приложения

| Адрес | Назначение |
| --- | --- |
| / | Список курсов и переход к записи |
| /requests/ | Список заявок |
| /requests/new/ | Форма создания заявки |
| /requests/<id>/ | Карточка заявки |
| /access-denied/ | Причина отказа |

## Проверка функций

1. Откройте форму новой заявки.
2. Заполните данные ребёнка и родителя, выберите подходящий по возрасту курс.
3. Отправьте форму и проверьте появление заявки в списке.
4. Подайте заявку с возрастом вне диапазона выбранного курса — откроется страница отказа.
5. Перезапустите приложение командой `docker compose restart app` и убедитесь, что заявка осталась в списке.
